# Internal Rate Of Return

The Internal Rate of Return (IRR) is the discount rate that makes a project's Net Present Value (NPV) equal to zero. It serves as a decision metric comparing the project's expected return against a required hurdle rate.

## Key points

- The IRR is the discount rate where NPV equals zero.
- It is calculated using trial and error, Goal Seek, or the IRR function in Excel.
- The IRR decision rule is to accept projects where the IRR exceeds the hurdle rate.
- The IRR decision rule aligns with the NPV rule only if all negative cash flows occur before positive cash flows.
- When comparing mutually exclusive projects, the highest NPV should be chosen, not necessarily the highest IRR.
- The IRR is a project characteristic, distinct from the market-determined opportunity cost of capital.
