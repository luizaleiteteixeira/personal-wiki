# Hypothesis Testing Procedure

Hypothesis testing is a method used to analyze sample data to determine if there is enough evidence to challenge the existing belief or status quo. This involves setting up null and alternative hypotheses and comparing the sample evidence against a threshold.

## Key points

- The null hypothesis ($\text{H}_0$) represents the status quo.
- The alternative hypothesis ($\text{H}_a$) is what the researcher seeks to prove.
- The T-statistic is calculated as (sample average - $\text{k}$) / SE.
- The P-value indicates the probability of observing the sample data if the null hypothesis were true.
- Decision rule: Reject $\text{H}_0$ if P-value < $\alpha$.
- For proportions, the Z-score formula is (population average - number we want to see) / SE.
